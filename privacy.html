Privacy policy

This policy describes the privately operated Hermes personal-assistant installation linked from this site. It is intended for its account owner's personal use, not public registration.

Google user data accessed

When authorised, the installation can access email content, headers, labels and attachments; calendar events; selected Drive files and documents; spreadsheet content; contacts; and task information. Actual access is limited by the permissions granted and the functions being used. Account authorisation tokens are stored separately from this public website.

Purpose and use

Google data is used to provide requested personal-assistant functions such as email organisation and summarisation, appointment and conflict checks, reminders, and document or spreadsheet updates. Sending messages or changing account data follows the account owner's instructions and applicable approval controls.

Processing and sharing

The private installation runs on owner-controlled infrastructure. Relevant data may be processed by configured third-party AI providers to generate requested assistance, and by configured messaging services to deliver requested results. Provider processing and retention depend on the selected provider and account settings. Do not assume that all processing occurs on the owner's server. This installation does not sell Google user data or use it for advertising, and does not itself train general-purpose AI models.

Hermes's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage, security and retention

Private conversation records, extracted notes, document copies, operational logs and backups may retain information needed for the owner's assistant functions. OAuth credentials are kept in restricted-access storage, not in this public repository. There is no universal automatic deletion period; the owner controls the private records and backup retention. This public documentation site contains no mailbox, calendar, personal-note or token data.

Control and deletion

The owner can stop the integration and revoke Google access through Google Account connections. Revocation prevents future authorised API access but does not automatically delete previously retained private records. Deleting those records and any retained backups is a separate action controlled by the owner.

This website

These static pages have no login form, advertising, analytics scripts or application tracking cookies. GitHub Pages provides the hosting and may process visitor network and request information under GitHub's privacy statement.

Contact and changes

For questions or deletion requests concerning the installation, use the user-support email shown on its Google OAuth consent screen. This policy should be updated when the installation's data practices change.
