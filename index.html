Hermes — personal assistant

Hermes is a privately operated personal-assistant installation for its account owner. This website provides information about that installation and its Google account integration. It is not a public assistant service and has no public sign-up or sign-in.

What the assistant does

With the owner's permission, the assistant can help organise email, review upcoming calendar events, identify scheduling conflicts, maintain personal reminders, and work with selected documents and spreadsheets.

Google account permissions

The private installation uses Google's OAuth consent process. Depending on the permissions granted, it can access Gmail, Calendar, Drive, Sheets, Docs, Contacts and Tasks. Email sending, calendar changes and document updates are subject to the owner's instructions and authorisations. No Google login, OAuth callback, credentials or account data are hosted on this public website.

Private installation, public documentation

This site contains static documentation only. The assistant, its administration tools, account tokens, messages, calendar events and personal notes are not published here.

This is an independently operated installation using Hermes Agent software, not the official website of Nous Research or a Google product.

Please read the privacy policy and terms of use. For support about the private installation, use the user-support email displayed on its Google OAuth consent screen.
